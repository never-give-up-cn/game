# 工厂建造者 - 2D 网格地图游戏

一个基于 Python + Pygame 的 2D 网格地图游戏。支持地图格子系统、建筑放置、斜向移动和背包物品管理。

## 快速开始

```bash
# 安装依赖
pip install pygame

# 启动游戏
python game_window.py
```

## 操作说明

| 按键 | 功能 |
|------|------|
| `W A S D` / 方向键 | 移动角色 |
| `W + A` / `W + D` 等 | 斜向移动（同时按住两个键） |
| `1 ~ 8` | 选择背包物品格 |
| `B` | 进入 / 确认放置建筑 |
| `TAB` | 切换建筑类型（放置模式） |
| `ESC` | 取消放置 / 关闭帮助 |
| `H` | 开关帮助 |
| `Q` | 退出游戏 |

## 功能特性

### 2D 网格地图
- 20 × 12 格子地图，每个格子独立定位
- 建筑占用矩形区域，玩家不可穿越
- 转角碰撞检测：斜向移动时防止穿墙

### 建筑系统
| 建筑 | 占地 | 说明 |
|------|------|------|
| 工厂 | 2×2 | 生产建筑 |
| 住宅 | 1×1 | 居住建筑 |
| 仓库 | 2×1 | 存储建筑 |
| 研究所 | 2×2 | 科技建筑 |
| 城墙 | 3×1 | 防御建筑 |

### 背包系统
- 2 行 × 8 格物品栏
- 数字键 1-8 选择物品
- 物品类型：材料、食物、工具、货币
- 支持堆叠、添加/移除

### 图形界面
- Pygame 彩色窗口渲染
- 建筑按类型分色
- 右侧信息栏显示玩家状态、建筑列表、背包摘要
